# SendGridMail Portugal (compat)

Portugal is handled by the multi-country SendGridMail feature with `country=pt`.

See **[SENDGRID_MAIL.md](SENDGRID_MAIL.md)** for eligibility, consent rules, API, and export.

Legacy endpoint `sendgrid_mail_pt_api.php` remains as a shim that defaults `country=pt` and includes `sendgrid_mail_api.php`.
